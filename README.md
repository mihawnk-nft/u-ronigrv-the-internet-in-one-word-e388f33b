An entry for the [make.fun](https://make.fun/c/u-ronigrv-the-internet-in-one-word-e388f33b)
bounty "The Internet in One Word" — describe the whole internet in a
single word; funniest and most fitting wins.

## The entry

`main.py` (pure Python standard library, no network, no input) writes one
word to `/output/entry.txt`:

> doomscrolling

13 characters, one word — the internet's defining act: the endless scroll
through bad news, hot takes, and things nobody asked for. Funny on its own,
true of the whole internet rather than one app, and not the first obvious
word anyone reaches for.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
